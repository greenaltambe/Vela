# Task 23: design foundation

Phone: OPPO CPH2707, Android 16, 90 Hz render rate (11.1 ms frame budget), arm64. Throwaway account `google:xxxxxx`. Nothing was committed. Screenshots: `docs/reports/23-screens/` (phone: `phone-*.png`, desktop 360x800 and 1280x800: `desktop-*.png`).

## 1. Summary

Built (bar and mini player options added after the owner's follow-up: floating / docked / minimal, label modes, shrink on scroll, regular or picture-in-picture mini player, attached or apart with a distance, same width as the bar): the Subscriptions fixes with measurements (part A), the token and theming layer with 18 new appearance settings (B), the motion system wired into the shell, lists, buttons and settings (C), a floating pill bar / collapsible rail / avatar + Profile menu with Settings removed from the bars (D), and the settings reorganisation with generated summaries, undo toasts, reset-per-page, search jump and the Customize hub with Color, Text, Icons & shapes, Glass and Tabs pages (E). DeArrow is now off by default (owner request). **Not met: the janky-frame target.** The main-thread work our own code did on Subscriptions fell from about 3-4 s to about 0.1 s per 12 s window, but janky frames stayed at 5-6% (target 3%); a trivial screen on this phone scrolls at about 9% janky, and the samples put 42% of busy time in the accessibility tree (an accessibility service is enabled on this phone). Several pieces are explicitly not done (section 5).

## 4. Decisions the spec didn't dictate

- **Settings cache key by database:** one in-memory read-through cache per database (weakly held) so every store instance shares it; all writes go through `SqlDelightSettingsStore` (the one direct SQL delete is routed through it).
- **Feed page size 60** and prefetch window 60; the feed cache itself stays 500 rows (the old cap).
- **Frosted glass = tint only** (0.88 minimum opacity, contrast-tested) because there is no stable backdrop blur in Compose; the bar sits below the page rather than over it.
- **Icon style default FILLED** (the existing look); outline strokes the same paths.
- **Accent softening:** nudge towards white/black until text-sized accent reaches 4.5:1 on page and surface; "Exact" keeps the pick.
- **A Look is only `look.*` keys + pure black + performance mode**; navigation tab list/order is a look key (`look.nav.*`).
- **Three bar styles:** the follow-up said "3 levels" and named two (floating, docked); the third is Minimal, from the design brief. Tell me if you meant something else.
- **Picture-in-picture mini player shows the video's thumbnail with controls**, not live video (the player's surface lives on the video page).
- **Shorts has no tab of its own** (it is a section of Subscriptions); the tab list offers Home, Subscriptions, Library, Search, Downloads.
- **Settings pages with no settings behind them were not created** (Gestures & controls, Captions, Search, Notifications, Linux integration); they arrive with their settings.
- **Settings is opened on top of the current page** (Back returns), not as a tab.

## 5. Known issues / unverified assumptions / NOT done

- Janky-frame target missed (5-10% on this phone; baseline of a trivial screen ~9%). Cause of the remaining time is outside our data code (accessibility traversal 42%, composition 43% of busy samples); not proven what it would be on a phone without an accessibility service. The list-query guard has not been mutation-tested.
- **Not done:** a live video picture in the mini player, swipe-to-skip on it, bundled OFL fonts (and verified font effect), "accent from the playing video", large collapsing page titles, pull-to-refresh brand animation, mini player <-> full player drag, predictive-back progress animation, swipe between tabs, mini player styles, the Looks screen and the four "next update" Customize parts, "Customize by tapping", icon packs, alternate app icons, real backdrop blur, per-animation jank numbers.
- Not looked at: the frame-time overlay on either platform; Linux frame-time log; the profile menu and rail on Linux with the real app (desktop UI tests and screenshots only); first-content timing; History and Channel numbers.
- Accessibility service found on the phone (`com.screenzen`); I did not change it.
- My mistakes this run, all contained: an early script step sent Back from the app root, so a later tap hit the phone's launcher and opened AnkiDroid (I did nothing inside it; I closed it) and two screenshots captured personal launcher/AnkiDroid content, which I **deleted** (none is in the repo); stray taps on the Customize pages set the icon style to Outline, which I reset to defaults; the synthetic data seeded on the throwaway account was removed. The default theme is unchanged.
- Existing installs: DeArrow turns off (no stored value, so the new default applies); anyone who wants it turns it on in SponsorBlock & extras.
